# Gemlocks (Client)
A two-player game where each player tries to crack the other’s secret code. It’s fast-paced and perfectly suited for integration with crypto transactions and decentralized technology.

## Install
```npm install```

## Setup
- create ```.env``` file @ root folder and write:
```
EXPO_PUBLIC_API_HOST=localhost
EXPO_PUBLIC_API_PORT=3030
```

## Run
```npx expo start```

### Server
You can find it at: https://github.com/mnapo/gemlocks-sv
