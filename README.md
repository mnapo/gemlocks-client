# Gemlocks

MVP web client for the Gemlocks code-deduction game.

## MVP

- 1 vs 1: player vs machine
- Four unique glyphs per code
- Numeric glyph set (0–9)
- Code selection timer
- Guess scoring: perfect / regular
- Difficulty setting
- Nickname and light/dark mode settings

The game model is intentionally built around **glyphs** rather than numbers so future sets can include emojis, runes, zodiac signs and other unlockable symbols.

## Future

- Global matchmaking
- Player ranks
- Online 1 vs 1 matches
- Blockchain-based game provability
- In-game currency and purchases
- Powers, hints, skins, backgrounds, avatars and glyph sets
